# tarot-reels-skill

Skills de Claude Code para edición de reels de Instagram/Meta Ads con HyperFrames.

## Instalar

```bash
npx skills add tuusuario/tarot-reels-skill --skill reels-editor
```

## Requisitos

- Node.js 20+, FFmpeg en el PATH
- Python 3.10+ con faster-whisper (`pip install faster-whisper`)
- HyperFrames: `npm create hyperframes@latest`
